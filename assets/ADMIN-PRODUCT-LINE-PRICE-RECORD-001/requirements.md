# 商品管理端：划线价搜索与导入导出记录调整

## 一、商品列表搜索调整

### 1. 是否为划线价商品

商品列表搜索区域增加“是否为划线价商品”筛选项。

- 接口：`GET /api/rsProduct/v1/admin/product/productPage`
- 请求方式：Query 参数
- 参数名：`linePriceFlag`

| 前端选项 | 参数值 | 含义 |
| --- | --- | --- |
| 全部 | 不传 | 不按照划线价筛选 |
| 是 | `1` | `productLinePrice` 不为空 |
| 否 | `0` | `productLinePrice` 为空 |

交互要求：

- 使用可清空的下拉选择框。
- 点击搜索时将该参数随商品列表查询一起提交。
- 点击重置时清空该条件并重新查询第一页。

### 2. 划线价生效日期区间

商品列表搜索区域增加“划线价生效日期区间”筛选项。

- 控件类型：日期时间范围选择器，需要支持到秒。
- 时间格式：`yyyy-MM-dd HH:mm:ss`

| 参数名 | 类型 | 含义 |
| --- | --- | --- |
| `linePriceEffectiveStartTime` | String | 所选区间开始时间 |
| `linePriceEffectiveEndTime` | String | 所选区间结束时间 |

交互要求：

- 用户选择完整范围后，同时提交开始时间和结束时间。
- 用户清空范围后，两个参数都不要提交。
- 点击重置时清空该范围并重新查询第一页。
- 后端使用“有效期有交集”规则查询，不要求商品有效期完全包含在所选区间内。
- 使用日期区间筛选时，没有配置划线价开始时间或结束时间的商品不会命中。

后端查询规则：

- 商品划线价结束时间大于等于所选开始时间。
- 商品划线价开始时间小于等于所选结束时间。

### 3. 商品列表响应中的划线价字段

商品列表返回位置：`data.records[]`。

| 字段名 | 类型 | 含义 |
| --- | --- | --- |
| `productLinePrice` | Number | 商品划线价格 |
| `linePriceStartTime` | String | 划线价开始时间 |
| `linePriceEndTime` | String | 划线价结束时间 |

时间响应格式均为 `yyyy-MM-dd HH:mm:ss`。

## 二、导入导出记录调整

### 1. 记录查询接口

- 接口：`POST /api/admin/rs-backend/importExportRecord/getRecordByParam`
- 响应：标准响应结构，记录数组位于 `data`。
- 该接口只返回近 48 小时的记录。

商品模块请求参数：

| 参数名 | 是否必填 | 参数值及含义 |
| --- | --- | --- |
| `moduleName` | 是 | 固定传 `rsProduct-product` |
| `operateType` | 否 | `1` 导出、`2` 导入；不传查询全部 |

### 2. 增加“成功/失败”列

导入导出记录表格增加一列：

- 表头：`成功/失败`
- 展示格式：`成功数量/失败数量`
- 示例：`100/23`

响应字段：

| 字段名 | 类型 | 含义 |
| --- | --- | --- |
| `successCount` | Integer | 导入成功数量 |
| `failCount` | Integer | 导入失败数量 |

建议展示规则：

| 记录状态 | 展示内容 |
| --- | --- |
| 导入完成 | 按“成功数量/失败数量”展示，例如 `100/23`；空值按照 `0` 处理 |
| 导入处理中 | `-/-`，避免显示 `0/0` 造成已完成的误解 |
| 导出记录 | `-` |
| 历史数据字段为空 | 兼容空值，不显示 `undefined/null` |

### 3. 状态和失败文件说明

| 状态值 | 含义 |
| --- | --- |
| `1` | 导出中 |
| `2` | 导出成功 |
| `3` | 导出失败 |
| `4` | 导入中 |
| `5` | 导入成功，所有数据均成功 |
| `6` | 导入存在失败数据 |

注意事项：

- 状态为 `6` 不代表所有数据都失败，可能出现 `100/23` 这种部分成功结果。
- 状态为 `6` 且 `filePath` 有值时，继续展示“下载失败数据”操作。
- 状态为 `5` 时，正常展示最终成功/失败数量，例如 `100/0`。
- 导入接口成功只表示任务已经创建，最终结果以导入导出记录为准。

## 三、验收点

- “是否为划线价商品”选择“是”时，只返回划线价不为空的商品。
- 选择“否”时，只返回划线价为空的商品。
- 日期时间范围精确到秒，并按有效期交集规则返回商品。
- 搜索重置后，新增加的两个条件都被清空。
- 导入记录完成后能够展示类似 `100/23` 的成功/失败数量。
- 导出记录和处理中记录不会错误显示为 `0/0`。
- 部分成功的导入记录仍能下载失败数据文件。
